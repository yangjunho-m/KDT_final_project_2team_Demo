# 시나리오 규칙 초안

## 공통

- 동일 `seed`와 시나리오 ID는 같은 결과를 재현해야 합니다.
- 프론트는 이탈 방향과 복귀 경로를 직접 지정하지 않습니다.
- 백엔드가 계획 위치, 실제 위치, GNSS 보고 위치, Cross-view 위치를 분리해 계산합니다.

## 재밍

- GNSS 위성 수와 GNSS 상태를 저하시킵니다.
- 실제 위치는 관성항법 drift 기준으로 천천히 계획 경로에서 벗어납니다.

## 스푸핑

- 실제 위치와 GNSS 보고 위치가 달라질 수 있습니다.
- Cross-view 자동 실행 조건을 만족하면 inference job을 순차 생성합니다.

## 복구

시나리오 종료 후 드론은 계획 경로로 부드럽게 복귀합니다. 복귀 중에는 `RECOVERING` 상태를 사용합니다.
